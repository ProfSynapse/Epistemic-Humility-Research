Gemma-3-4B-IT is a 4-billion-parameter instruction-tuned Gemma 3 language
model. This paper uses it as one of two main reference models for subliminal
learning and steering-vector mediation experiments.

**Why it matters here:** Its weaker subliminal-learning effect than the Qwen
reference model shows that susceptibility differs across model families.

**Lineage:** It is an instruction-tuned member of the Gemma 3 model family.
