Pythia-6.9B is a 6.9-billion-parameter autoregressive language model in the Pythia suite. The paper uses it for a controlled gendered-pronoun intervention and probing demonstration.

**Why it matters here:** It provides a multi-billion-parameter case for comparing causal localization with linear decodability.

**Lineage:** It is a member of the Pythia model suite.
