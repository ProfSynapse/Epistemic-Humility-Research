A dataset of 6,084 balanced true/false factual sentences across six topics (Cities 1,458; Inventions 876; Chemical Elements 930; Animals 1,008; Companies 1,200; Scientific Facts 612). For the first five topics, false statements are generated by swapping property values across entities from a reliable reference table. Scientific Facts were generated by ChatGPT and verified by two human annotators. Designed so that a classifier must generalize across disjoint topics.

**Why it matters here:** Provides the controlled topic-disjoint training/test regime needed to evaluate whether a probe recovers a general truthfulness representation rather than topic-specific surface statistics. Enables cross-topic generalization testing as the evaluation protocol.

**Lineage:** Created by Azaria and Mitchell (2023, arXiv 2304.13734) for the SAPLMA evaluation. Distinct from TruthfulQA (adversarial generation) and FEVER (passage-grounded verification).
