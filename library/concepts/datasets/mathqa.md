MathQA is a large-scale dataset of grade-school-to-college-level math word
problems, each paired with a multiple-choice answer set and an annotated
operation program specifying the sequence of arithmetic operations that
derives the answer, built to support both answer-accuracy and
reasoning-program evaluation.

**Why it matters here:** it is one of the math-reasoning evaluation splits
used to test whether interventions on massive-activation rigidity improve
structured multi-step reasoning, alongside GSM8K, AIME, and MATH500.
