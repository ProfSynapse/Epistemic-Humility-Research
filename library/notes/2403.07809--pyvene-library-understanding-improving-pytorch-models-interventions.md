## Abstract

Interventions on model-internal states are fundamental operations in many areas of AI, including model editing, steering, robustness, and interpretability. To facilitate such research, we introduce $\textbf{pyvene}$, an open-source Python library that supports customizable interventions on a range of different PyTorch modules. $\textbf{pyvene}$ supports complex intervention schemes with an intuitive configuration format, and its interventions can be static or include trainable parameters. We show how $\textbf{pyvene}$ provides a unified and extensible framework for performing interventions on neural models and sharing the intervened upon models with others. We illustrate the power of the library via interpretability analyses using causal abstraction and knowledge localization. We publish our library through Python Package Index (PyPI) and provide code, documentation, and tutorials at this https URL .

## Summary

The paper introduces pyvene, an open-source library that makes intervention schemes first-class, serializable configurations around PyTorch models. It supports activation replacement, addition, collection, trainable interventions, and multi-source parallel or serial interventions across feed-forward, convolutional, recurrent, and Transformer models. The paper reproduces causal tracing in GPT2-XL and compares a trainable one-dimensional causal intervention with a linear probe on a gendered-pronoun task in Pythia-6.9B.

## Extracted numbers

- The GPT2-XL causal-tracing reproduction implements the paper's main experiment in about 20 lines of pyvene code and reproduces Figure 1 from Meng et al. (2022) (Section 3, Figure 2).
- The Pythia-6.9B pronoun task uses 47 typically male names and 10 typically female names, and the unmodified model reaches 100% task accuracy (Section 4).
- A one-dimensional trainable DAS intervention localized gender to a sparse set of layers and token positions, while a linear probe reached 100% classification accuracy at almost all tested components (Section 4, Figure 3).
- At publication, the project site included more than 20 tutorials covering intervention complexity and multiple model architectures (Section 1).

## Relevance to experiment

pyvene supplies an implementation pattern for activation collection, replacement, trainable causal alignment, and joint training with interventions. The paper's gender case study also demonstrates why widespread probe accuracy does not identify the sites where a representation causally affects behavior. This is a software and demonstration paper, not evidence that any answerability variable has been internalized into model weights.

## Claims

- Evidence label: system. pyvene expresses static, trainable, parallel, serial, and decoding-time interventions as serializable configurations around PyTorch models (Section 2).
- Evidence label: reproduction. A compact pyvene implementation reproduces the causal-tracing pattern reported for GPT2-XL factual associations (Section 3, Figure 2).
- Evidence label: intervention. On a controlled Pythia-6.9B pronoun task, a one-dimensional trainable intervention finds a much sparser causal localization of gender than a high-accuracy linear probe suggests (Section 4, Figure 3).
