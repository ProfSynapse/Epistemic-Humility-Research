## Abstract

Low-Rank Adaptation (LoRA) is a standard tool for parameter-efficient finetuning of large models. While it induces a small memory footprint, its training dynamics can be surprisingly complex as they depend on several hyperparameters such as initialization, adapter rank, and learning rate. In particular, it is unclear how the optimal learning rate scales with adapter rank, which forces practitioners to re-tune the learning rate whenever the rank is changed. In this paper, we introduce Maximal-Update Adaptation ($μ$A), a theoretical framework that characterizes how the "optimal" learning rate should scale with model width and adapter rank to produce stable, non-vanishing feature updates under standard configurations. $μ$A is inspired from the Maximal-Update Parametrization ($μ$P) in pretraining. Our analysis leverages techniques from hyperparameter transfer and reveals that the optimal learning rate exhibits different scaling patterns depending on initialization and LoRA scaling factor. Specifically, we identify two regimes: one where the optimal learning rate remains roughly invariant across ranks, and another where it scales inversely with rank. We further identify a configuration that allows learning rate transfer from LoRA to full finetuning, drastically reducing the cost of learning rate tuning for full finetuning. Experiments across language, vision, vision--language, image generation, and reinforcement learning tasks validate our scaling rules and show that learning rates tuned on LoRA transfer reliably to full finetuning.

## Summary

Chen, Villar, and Hayou study how LoRA learning-rate optima change with adapter
rank, initialization, and the effective LoRA multiplier. They propose
Maximal-Update Adaptation, a scaling framework intended to keep feature updates
stable as width and rank vary.

The key result for this project is not "increase rank and keep everything else
fixed." The paper identifies one regime where the optimal learning rate is
roughly rank-invariant and another where it scales inversely with rank. It also
argues that a particular LoRA configuration can make learning-rate tuning
transfer from LoRA to full fine-tuning.

## Extracted numbers

- Section 1 / Figure 2: the paper reports two qualitative scaling regimes for
  LoRA rank changes: rank-invariant learning-rate optima in one configuration
  and decreasing optima with increasing rank in another.
- Appendix B.6: dense rank-grid checks include ranks 16, 32, 64, 128, and 256
  for the transfer setting.
- Section 5.3 / Figure 6: the RLVR setting includes GSM8K with Llama-3.1-8B and
  validates the rank-scaling rules beyond SFT.

## Relevance to experiment

Our clean response-confidence runs all use LoRA rank 32, alpha 64, dropout 0.05.
Therefore, current results cannot adjudicate LoRA-rank sensitivity. If we add a
LoRA panel, rank should not be changed in isolation: learning rate and the
effective LoRA multiplier need a governed panel, and the first question should
be whether behavior changes are due to update scale rather than rank itself.

## Claims

- Mechanism: LoRA rank and learning rate are coupled. Section 1 and Figure 2
  describe one rank-invariant regime and one inverse-with-rank regime.
- Method: Maximal-Update Adaptation is proposed as the scaling rule for stable,
  non-vanishing LoRA feature updates across rank and width.
- Design implication: a LoRA-rank sweep for this project should include a
  learning-rate rule or panel, not only `r` changes.
