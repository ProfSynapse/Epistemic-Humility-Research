## Abstract

Feed-forward layers constitute two-thirds of a transformer model's parameters, yet their role in the network remains under-explored. We show that feed-forward layers in transformer-based language models operate as key-value memories, where each key correlates with textual patterns in the training examples, and each value induces a distribution over the output vocabulary. Our experiments show that the learned patterns are human-interpretable, and that lower layers tend to capture shallow patterns, while upper layers learn more semantic ones. The values complement the keys' input patterns by inducing output distributions that concentrate probability mass on tokens likely to appear immediately after each pattern, particularly in the upper layers. Finally, we demonstrate that the output of a feed-forward layer is a composition of its memories, which is subsequently refined throughout the model's layers via residual connections to produce the final output distribution.

## Claims

- Feed-forward layers in transformer language models operate as unnormalized key-value memories: the first weight matrix acts as keys correlating with textual input patterns and the second as values inducing next-token vocabulary distributions. (Section 2, Figure 1) [[ffn-as-key-value-memory]]
- Lower layers (1-9) of a 16-layer transformer predominantly capture shallow n-gram input patterns while upper layers (10-16) capture semantic patterns; 65-80% of top trigger examples per key were associated with at least one human-recognizable pattern. (Figure 2, Table 1, Section 3.2) [[layer-depth-pattern-hierarchy]]
- In the upper layers, value vectors' top vocabulary prediction matches the next token of the key's top trigger example at ~3.5% rate—orders of magnitude above the 0.0004% random baseline—showing upper-layer memory cells store semantically predictive associations. (Figure 4, Figure 5, Section 4)
- A typical feed-forward layer activates 10-50% of its 4,096 memory cells per input; in ≥68% of examples the layer's composite output prediction differs from every individual memory cell's prediction, demonstrating genuine intra-layer compositional emergence. (Figure 7, Figure 8, Section 5.1) [[intra-layer-memory-composition]]
