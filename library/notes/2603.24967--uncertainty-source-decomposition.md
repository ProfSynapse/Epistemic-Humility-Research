## Abstract

Understanding why a large language model (LLM) is uncertain about the response is important for their reliable deployment. Current approaches, which either provide a single uncertainty score or rely on the classical aleatoric-epistemic dichotomy, fail to offer actionable insights for improving the generative model. Recent studies have also shown that such methods are not enough for understanding uncertainty in LLMs. In this work, we advocate for an uncertainty decomposition framework that dissects LLM uncertainty into three distinct semantic components: (i) input ambiguity, arising from ambiguous prompts; (ii) knowledge gaps, caused by insufficient parametric evidence; and (iii) decoding randomness, stemming from stochastic sampling. Through a series of experiments we demonstrate that the dominance of these components can shift across model size and task. Our framework provides a better understanding to audit LLM reliability and detect hallucinations, paving the way for targeted interventions and more trustworthy systems.

## Summary

Taparia et al. argue that single-score and aleatoric/epistemic uncertainty estimates are too coarse to guide targeted reliability improvements in LLMs. They propose a three-component decomposition: U_input (input ambiguity, from prompt vagueness), U_know (knowledge-gap uncertainty, from insufficient parametric evidence), and U_dec (decoding randomness, from stochastic sampling). Each component is measured independently: U_input uses K=5 semantically equivalent paraphrases generated by GPT-5-nano and computes disagreement across their outputs; U_know uses an M=5 LoRA ensemble (rank 8, alpha 32, dropout 0.1, lr 2e-5) trained on in-domain data and measures ensemble disagreement; U_dec generates N=5 repeated samples under stochastic decoding strategies and measures semantic disagreement. Correctness labeling uses ROUGE-L >= 0.3 as a fuzzy-match proxy and bidirectional NLI entailment at threshold gamma=0.5 for the formal definition. Experiments run on Llama 3 (8B) and Gemma 3 (1B, 4B, 12B, 27B) across TriviaQA (open-domain factual) and GSM8K (mathematical reasoning). On TriviaQA, decoding randomness is the strongest failure predictor for Llama 3 8B (AUROC 0.731), while input ambiguity is strongest for Gemma 3 27B (AUROC 0.761); knowledge-gap uncertainty is near chance on TriviaQA for both models (AUROC 0.499/0.498). On GSM8K, knowledge-gap uncertainty is comparatively less degraded (AUROC 0.598/0.500) versus input (0.518/0.334) and decoding (0.533/0.383). A 3x3 joint heatmap analysis shows failure rate spans 0.17 (both low) to 0.83 (both high), and calibration quality inverts: ECE is worst (0.635) when both scores are low, best (0.125) when both are high. Stochastic decoding strategies (top-k, top-p, temperature) yield higher AUROC for U_dec than deterministic ones (greedy, beam search). For smaller Gemma 3 models (1B), decoding uncertainty is the stronger predictor; for larger models (12B, 27B), input ambiguity becomes more reliable, though the paper notes no strictly monotonic trend across the full size range. The three components are not strictly orthogonal and their sum can exceed total uncertainty.

## Relevance to experiment

The three-component decomposition gives a diagnostic lens that is directly applicable after Phase 1 training arms: measuring U_input, U_know, and U_dec before and after SFT/DPO/KTO would reveal which uncertainty source each training signal actually shifts, rather than conflating them into a single AUROC. The joint heatmap finding has a concrete implication for the experiment: models with low uncertainty on both components are the worst calibrated (ECE 0.635), which means high-confidence predictions are not reliably well-calibrated -- a pattern worth checking against the Synaptic Tuner evaluation substrates TriviaQA and GSM8K. The LoRA ensemble method for knowledge-gap estimation is a tractable compute budget given the experiment's existing LoRA infrastructure, since the hyperparameters (r=8, five adapters, one epoch) are modest. The shared evaluation substrates (TriviaQA, GSM8K) and models (Llama 3 8B; Gemma 3 family overlaps with similar scales) make the results directly comparable to existing benchmark rows in the graph. One caution: the paper evaluates Llama 3 and Gemma 3, not Qwen3; applicability to Qwen3 checkpoints used in the study would need to be verified empirically. The paper does not report training-intervention deltas, so it does not populate effects.csv directly, but it supplies a measurement protocol that could generate such deltas if applied before and after each Phase 1 arm.

## Claims

- The three-component decomposition (U_input, U_know, U_dec) predicts that the dominant source of uncertainty shifts with model size and task: for Llama 3 (8B) on TriviaQA, decoding randomness dominates (AUROC 0.731); for Gemma 3 (27B) on TriviaQA, input ambiguity dominates (AUROC 0.761); knowledge-gap uncertainty is near chance (AUROC ~0.499) on TriviaQA for both models. (Table 1) (uncertainty-source-decomposition) [[uncertainty-source-decomposition]]
- The joint analysis of U_input and U_dec reveals an inverse calibration pattern: when both scores are low, failure rate is minimized (0.17) but calibration is worst (ECE 0.635); when both are high, failure rate is maximized (0.83) but calibration is best (ECE 0.125). (Figure 5) (dominant-uncertainty-source-shifts-with-model-scale) [[dominant-uncertainty-source-shifts-with-model-scale]]
- On the mathematical reasoning task GSM8K, knowledge-gap uncertainty (U_know AUROC 0.598/0.500) is comparatively less degraded than on TriviaQA (0.499/0.498), while input and decoding uncertainty AUROC values are all below 0.55, suggesting task structure moderates which uncertainty source is informative. (Table 1) (uncertainty-source-decomposition) [[uncertainty-source-decomposition]]
- Stochastic decoding strategies (top-k, top-p, temperature sampling) yield significantly higher AUROC for U_dec than deterministic methods (greedy, beam search) across all tested Gemma 3 model sizes. (Figure 4(b), Section 4.3) (decoding-randomness) [[decoding-randomness]]
- The LoRA ensemble (M=5, r=8, alpha=32) provides the knowledge-gap uncertainty estimate by measuring disagreement across independently trained adapters, and its hyperparameter budget is modest enough to run within standard fine-tuning infrastructure. (Table 2, Appendix A.4) (lora-ensemble) [[lora-ensemble]]
