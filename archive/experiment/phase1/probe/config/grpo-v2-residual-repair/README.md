# GRPO v2 Residual And Repair Config Archive

This directory archives legacy Phase 3 current-clean GRPO v2 residual caution,
knowledge-boundary, and L26 repair direction/intervention configs formerly
stored under `experiment/phase1/probe/config/`.

Migration subset: the GRPO v2 residual/read-trajectory/intervention and L26
repair slices from `docs/migration/phase1-probe-config-terrain.md`.

Owner decision: archive-only historical provenance for GRPO v2 caution-vs-doubt
and L26 repair/protection follow-up work. No migrated `experiments/<slug>`
owner was present, and these configs are not reusable shared defaults.

The component group contains residual read-trajectory and intervention configs
for the caution axis, the caution-perpendicular refinement, a knowledge-boundary
steering config, and direction-transform configs for known-overrefusal and
unknown-failure L26 repair vectors.

Non-goal: generated residual-direction, direction-transform,
read-trajectory, steering, and intervention outputs under
`experiment/phase1/probe/` are preserved as historical run provenance.
