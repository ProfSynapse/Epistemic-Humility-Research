# Paper 4 Source Artifacts

This directory is the paper-local source-artifact snapshot for Paper 4
(`paper-4-two-signal-readout`). These files were moved out of the shared
locked training-regimen probe tree so the paper builder and manuscript cite a stable
paper-owned provenance bundle.

The result artifacts consumed by the Paper 4 builder and manuscript live under:

`probe/`

The complete old-to-new path map is tracked at
`docs/migration/paper4-source-artifact-map.json`.

The runtime calibration-artifact bundle was not moved in this lane because the
Paper 4 builder and manuscript do not consume it.
