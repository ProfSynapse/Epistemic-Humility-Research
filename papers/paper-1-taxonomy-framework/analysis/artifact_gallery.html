Abstention operating points

CSV Markdown

Includes Cheng IDK rows and AbstentionBench model-frontier rows. The generated note says these sources use different datasets and metric definitions, so they should not be pooled or compared as one frontier.

  • Cheng IDK rows report recall and exact over-refusal on known-answer items.
  • AbstentionBench rows report median recall, median precision, and an over-refusal-sensitive proxy defined as 100 minus median precision.
