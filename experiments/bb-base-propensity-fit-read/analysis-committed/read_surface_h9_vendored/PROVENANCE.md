## Why it is vendored here

The H9 experiment directory is NOT on `origin/main`; it lives only on the H9
branch. BB clones the repo at its own signed commit (off `main`), so the H9
manifest is not reachable from the clone. Copying the manifest into BB's own
`analysis-committed/` makes BB self-contained and removes a dependency on H9
being merged. The `qhash` binding is preserved verbatim, so the SAME 750
questions in the already-staged private pool
(`professorsynapse/eh-h9-holdout-pool`, file `holdout_pool_enlarged.jsonl`) are
the read surface, and the Modal join re-verifies each row's qhash against this
copy. Reusing H9's exact draw (rather than a fresh one) is deliberate: it makes
BB and H9 the SAME row population on the SAME staged text, differing only in the
model under test (untrained base vs the AI-TRUE checkpoint), which is what makes
them a clean before/after-training bookend for the propensity read.

Do not edit this file. If the upstream H9 manifest ever changes, re-vendor and
update the sha256 above.
