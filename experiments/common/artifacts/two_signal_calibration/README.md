# Two-Signal Calibration Artifacts

Portable calibration bundles for the two-signal reference runtime.

These artifacts were generated by `experiments/common/mechinterp/fit_calibration.py`
from the Qwen3-4B Instruct Amendment S/W extraction surfaces. They are shared
runtime inputs rather than a standalone evidence-producing experiment, so they
live under `experiments/common/artifacts/`.

Runtime consumers should load them through
`experiments/common/mechinterp/two_signal_runtime.py`; refits should use the default
`--out-dir` in `fit_calibration.py` unless intentionally writing a scratch copy.
