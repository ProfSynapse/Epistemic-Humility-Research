# SelfAware Gate Pool

Promoted shared input for experiments that need the frozen SelfAware
known-vs-unknown gate rows.

- `selfaware_gate_rows_frozen.jsonl` is the full committed gate-row pool.
- `selfaware_gate_rows_smoke300.jsonl` is the small cloud plumbing/smoke pool.
- `PROVENANCE.json` records the gitignored extraction rows this pool was
  distilled from.

Origin before promotion:
`experiment/phase1/probe/pools/`.
