Feature #73 reached its first successful training on the prepared local Docker path at run 11 (release `557ce1be`, engine `ce539b70`), and the verify cut then failed on B-10-R2 (#280). Six decisions are the user's, and one of them (Q6) changes a recorded ruling.

Consumers are named generically throughout: a desktop app on a user's machine, and a web app driving cloud compute.

> **Limitations**: the Modal and HF Jobs providers (2,512 lines sharing layers 1 and 7) were not inventoried; no named pipe was ever opened, so the Engine API costing is read-from-source; no test engineer was consulted (the architect supplied the test plan). See [Limitations](#limitations).
