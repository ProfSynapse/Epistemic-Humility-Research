Keep the sentinel partition as the provider/destination discriminator (parse-time, tested both directions; it is what keeps the section 28 gate honest). Keep the lazy-import provider dispatch at `cli.py:963-1114` as the single seam. Prefer narrowing an existing branch to adding an adapter: C1 deletes a divergence and trips none of the fenced categories; a reconciler between two source routes would be the compatibility layer the clause forbids. Four docker-versus-modal divergences are now measured: committed-blob read, provenance binding, source materializer (docker-only discipline), and `required_kinds` (Modal-only, `modal_resolver.py:768`, zero in `docker_training.py`), so C1 reconciles a superset rather than only tightening the weaker arm.
