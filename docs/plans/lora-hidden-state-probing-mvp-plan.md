## Summary

Build the MVP of the LoRA hidden-state probing tier: a correlational extraction harness that computes `h_base`, `h_lora`, and `delta = h_lora − h_base` for matched prompts at the final prompt-token across all layers, plus a model-free schema/validation layer and a GPU-free test suite. The architectural pivot, independently confirmed by all four specialists: the harness needs a **new plain HF Transformers + PEFT forward-pass path** (vLLM does not expose `output_hidden_states`), reusing the existing `backends.py` only for Qwen3 prompt-rendering + `enable_thinking=False` self-checks. This is exploratory mechanism tooling — it stays entirely off the locked PROTOCOL v0.3 headline path and the Amendment A/v0.4 track, writes to its own output subtree, and never mutates run records. Goal: get extraction working and ~90% test-covered on CPU **before** any real GPU experiment.

## Specialist Perspectives

### 📋 Preparation Phase
**Effort**: Low–Medium

#### Verified API Contracts (Context7, this session)
- `model(**inputs, output_hidden_states=True, use_cache=False, return_dict=True).hidden_states` = tuple of length **`config.num_hidden_layers + 1`** for a standard attention decoder (Qwen3); index 0 = embeddings, 1..N = block outputs; each tensor `[batch, seq_len, hidden_size]`. (The `N+2` form is Mamba-specific — do NOT generalize. Schema asserts count dynamically.)
- Final-prompt-token vector = `hidden_states[layer][:, -1, :]` — but literal `-1` is a left-padding footgun. **Use batch=1 for MVP** (or true-length `attention_mask.sum(-1)-1`).
- One-process base-vs-adapter contrast (verified): `with model.disable_adapter(): h_base = model(...)`; `model.set_adapter(name)` then `h_lora = model(...)`. Do NOT `merge_and_unload` for the primary path.
- Deterministic forward: `model.eval()`, `use_cache=False`, `torch.no_grad()`, fixed dtype/device, identical rendered prompt bytes, no sampling.
- `safetensors.torch.save_file(dict[str,Tensor], path, metadata=dict[str,str])`: tensors must be `.contiguous().cpu()`; metadata **values must be strings** → keep rich manifest in sidecar `manifest.json`, store only a hash in safetensors metadata.

#### Research Tasks (first-GPU-run gates, not GPU-free blockers)
- [x] Confirm `len(hidden_states) == config.num_hidden_layers + 1` on the real Qwen3-4B load. Local Docker SFT MVP confirmed `[37, 2560]` tensors, i.e. embeddings + 36 transformer layers.
- [x] Smoke-test loading a real **Unsloth/4.45.2-trained adapter into the newer inference PEFT** (cross-version skew is the #1 first-run risk); confirm `disable_adapter()` context-manager form + adapter naming. Local Docker run loaded the grouped-split SFT adapter with PEFT `0.18.1` / Transformers `4.57.6`, wrote `h_base`, `h_lora`, and `delta`, and finalized manifest `ok`.

**Effort**: Medium

#### Components Affected
| Component | Change Type | Impact |

| `probe/config/hidden_state_probe.yaml` | New | Pinned extraction config (the hashed SSOT) |

| `probe/tests/test_hidden_state_probe.py` | New | GPU-free fixture tests |

| `probe/tests/test_probe_smoke.py` | Modify (narrow) | Byte-identical regression for the extracted render helper |
| `probe/README.md` | Modify | Add "hidden-state extraction (exploratory tier)" section, separated from the stochastic probe |
| `probe/requirements-hidden-state.txt` | New | Inference deps decoupled from the Unsloth trainer island |

#### Design Approach (architect Decisions A–E, adopted)
- **A — Extract a shared render helper.** `_render_prompt`/`_apply_chat_template` are bound inside `VLLMBackend` (which constructs a vLLM engine), so the HF+PEFT harness cannot reuse them in place; re-implementing would create the forbidden "second Qwen3 chat-template path." Extract `render_probe_prompt(tokenizer, system_prompt, question, *, enable_thinking) -> str` (tokenizer injected → engine-agnostic), preserving `assert_no_think_scaffolding` verbatim. Both `VLLMBackend` and the harness call it. Acceptance: existing `test_probe_smoke.py` stays GREEN + one new byte-identical parity test.
- **B — 4-file single-responsibility split** (config = declaration; schema = model-free validation incl. P0 adapter-state pre-flight; harness = thin orchestration with lazy heavy imports; tests = GPU-free).
- **C — Output tree**: `probe/<model_tag>/hidden_states/<extraction_id>/` with `manifest.json`, `rows.jsonl`, and per-arm `h_base.safetensors` / `h_lora.safetensors` / `delta.safetensors` (optional `-NNNNN-of-MMMMM` sharding for large layer×token sets). `delta` is **persisted** (tamper-evident, cheap downstream). `extraction_id = f"{arm}__{extraction_config_sha[:12]}"`.
- **D — Exhaustive manifest**: base model id/revision/hash, adapter path/hash, active-adapter-name, adapter_state, merged_sanity flag, dtype/device, tokenizer revision, `enable_thinking`, prompt_renderer_hash, prompt_hash (per-row + corpus), source_split, layer_list, token_position_rule, tensor_shapes, persistence_format, **lora rank/alpha/dropout/target_modules**, research_repo_commit, submodule_commit, **`data_sha256`** (sha256 of the exact prompt-corpus/source-split bytes consumed — ties to the run_record identity spine), extraction_config_sha, aligned_probe_config_sha, aligned_run_record_id (**link, never mutate**), **peft/transformers versions**.
- **D-bis — Crash-safe manifest discipline** (run-records SACROSANCT pattern, architect addendum): **WRITE-BEFORE-INVOKE** — write the manifest with `status:"launched"` BEFORE the forward pass begins, then PATCH outcome / `tensor_shapes` / `verified` after. A crashed/partial extraction is then self-evident on disk (same property probe.py's resumable append-log gives). The `verified` flag is set TRUE **only** after checking against emitted tensors (GPU-smoke `h_base≠h_lora` passed + shard files exist) — never hand-set.
- **E — Two-tier adapter-state confound guard** (see Cross-Cutting).

#### Key Decisions
| Decision | Options | Recommendation | Rationale |
|----------|---------|----------------|-----------|
| backends.py reuse | extract / import-as-is / re-implement | **Extract** shared helper | Only path satisfying reuse + no-second-template-path; self-checks move verbatim |
| Tensor layout | per-row keyed / per-arm files | **Per-arm files** + optional sharding | Matches spec output tree, mmap-friendly for Phase-5 |
| Eval arms mirroring | by-value / by-convention | **By-value** (read adapter paths from eval config) | Extraction + behavioral eval provably hit same artifacts |
| `merged_sanity` | build / defer | **Defer** (keep enum slot) | MVP scope; matches "working before experiments" |
| dtype | native / fp32 | **fp32** for small MVP slice (config knob) — EXPLICIT, recorded as both `compute_dtype` (model native) + `persist_dtype` (fp32) in manifest; **never a silent cast** | Cuts numerical noise in delta; satisfies architect-addendum "no silent upcast/downcast" by recording both ends of the conversion |
| tensor compression | none / compress | **None for MVP** (architect addendum B) | mmap-ability > size for the small slice; revisit only if Phase-5 corpus grows |
| layer list / token position | — | **All layers / final prompt token** (config knobs) | Spec defaults; small slice cheap; expansion config-only |
| inference env | trainer pins / new env | **New env**, current transformers/peft/safetensors | Forcing onto Unsloth 4.45.2/0.7.1 risks fragility; no eval-side HF pin exists |

#### Implementation Sequence (CPU-first; each step GREEN before the GPU-only piece)

4. Selection/alignment: read `questions_frozen.json` keys + **stream** `probe_results.jsonl` by `probe_pool_row_key` (123MB — never whole-load) to build matched known/unknown slice.
5. `ExtractionBackend` Protocol + `StubExtractionBackend` (deterministic fixed-shape, no torch) + manifest/`rows.jsonl` writer + resume → end-to-end pipeline GREEN on CPU.
6. `TransformersPeftBackend` (lazy torch/transformers/peft; batch=1, `eval()`, `use_cache=False`, `no_grad`, fp32, pinned device; `disable_adapter()`→`h_base`, active→`h_lora`; reuse render helper) + GPU-smoke `h_base≠h_lora` assertion. *(GPU-only; not in CI)*
7. `tests/test_hidden_state_probe.py` (Step 5 fully covered) + README.

**Ownership**: backend-coder → Steps 1–6 + README; test-engineer → Step 7 + the Step-1 regression test (coordinate the byte-identical assertion).

#### Coverage Targets
- Model-free surface (schema + config + manifest + declared-adapter-state + prompt-hash): **90%+ line/branch incl. negative branches**.
- Necessarily untested until GPU smoke: real model/PEFT load, real `output_hidden_states`, numerical `h_base≠h_lora`, template honoring `enable_thinking=False`, dtype/device behavior.

#### Documented GPU-smoke assertions (built later, marked xfail/skip now)
base≠lora hidden states; non-trivial delta; byte-identical prompt + no `<think>` block on real template; tensor shape matches configured layer list & schema; manifest adapter hash/name matches loaded adapter; determinism across two forward passes; merged-sanity (if run) logged separately.

#### Test Data Needs
Tiny known/unknown JSONL fixture (train_fixture shape, from frozen split); small deterministic synthetic hidden-state tensor `(n_layers, seq_len, hidden_dim)` in serialized form (no torch hard-dep); `monkeypatch` path injection (test_probe_smoke style); **injectable synthetic-tensor extractor seam** — the one hard prerequisite on the coder.
